HSE Auto-Mentor RAG
Автонаставник для студентов МИЭМ НИУ ВШЭ — умная вопросно-ответная система (RAG), которая консультирует студентов по любым университетским документам.

Главная особенность текущей версии — полная автоматизация пополнения базы знаний. Система умеет самостоятельно обращаться к Google Диску, находить новые файлы и обучаться на них.

Умная синхронизация (Google API): Система подключается к облаку через сервисный аккаунт и автоматически сканирует папки на наличие новых инструкций и приказов.

Поддержка нативных форматов: Настроен экспорт документов, созданных непосредственно в Google Docs и Google Sheets.

Чтение таблиц (Excel): Парсер умеет извлекать данные из загруженных таблиц (XLSX) и переводить их в текстовый формат для нейросети.

Анализ PDF, DOCX и HTML: Система корректно читает сканированные документы и веб-страницы.

Структурирование (Header Injection): Каждому отрывку текста автоматически присваиваются "хлебные крошки" (категории), чтобы нейросеть лучше понимала контекст.

🏗️ Как устроена архитектура (Простыми словами)
Google Drive Sync: Скрипт-синхронизатор опрашивает Google Диск и формирует очередь из новых или измененных файлов.

Ingest Worker (Обработчик): Фоновый процесс скачивает файлы из очереди, разбивает их на смысловые абзацы (чанки) и превращает в векторы (эмбеддинги).

Векторная база данных: PostgreSQL с расширением pgvector хранит тексты и позволяет мгновенно находить нужные абзацы по смыслу вопроса.

Chat Service (Чат-сервис): Принимает вопрос студента, находит историю его прошлых сообщений в Redis (хранится 24 часа), ищет ответ в базе и передает нейросети для формирования красивого ответа.

Как запустить проект (Быстрый старт)
Шаг 1. Подготовка
Убедитесь, что в корне проекта лежит файл ключа google_creds.json (доступ к Google API).
В файле .env должны быть указаны настройки БД, Redis и ID папки Google Диска: GOOGLE_DRIVE_FOLDER_ID.

Шаг 2. Запуск инфраструктуры
Поднимаем базы данных (PostgreSQL и Redis) через Docker:

docker-compose up -d

Шаг 3. Инициализация и загрузка данных
Создаем таблицы в базе данных:

python scripts/init_db.py

Запускаем синхронизацию с Google Диском (поиск новых файлов):

python scripts/sync_drive_to_db.py

Запускаем фоновый обработчик (скачивание и индексация):

python -m services.ingest_worker.main

Шаг 4. Запуск API для чата
Включаем сервер, который будет отвечать на вопросы студентов:

uvicorn services.chat_service.main:app --reload --port 8001

🔌 API для интеграции (например, с Telegram-ботом)
GET /ping — Проверка статуса сервера.

POST /chat/stream — Отправка вопроса и получение ответа в режиме реального времени (потоковая передача SSE).

DELETE /chat/{user_id}/history — Очистка контекста диалога.

🐳 Сборка Docker-образа
Для развертывания проекта на сервере (Production) подготовлен Dockerfile.
Чтобы собрать готовый образ приложения, выполните команду в корне проекта:

docker build -t hse-rag-app .
