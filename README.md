# HSE Auto-Mentor RAG (MVP Phase 1)

**Профиль:** Автонаставник для студентов ВШЭ.
**Статус:** Реализован "Ingest Worker" (Пайплайн сбора данных).

## 🚀 Что сделано на данный момент:
1. **Архитектура "Пылесоса":** Реализован асинхронный воркер, который автоматически обрабатывает очередь документов из PostgreSQL.
2. **Универсальный парсинг:** Система умеет "высасывать" контент из:
   - Живых веб-страниц (hse.ru) с автоматической очисткой от навигации и рекламы (Readability алгоритм).
   - Локальных и сетевых PDF/DOCX файлов.
   - Реестров в формате XLSX.
3. **Векторное хранилище:**
   - Настроена база PostgreSQL с расширением **pgvector**.
   - Реализован быстрый поиск через **HNSW индексы**.
   - Текст автоматически конвертируется в 1024-мерные векторы моделью `mxbai-embed-large-v1`.
4. **Header Injection:** В каждый фрагмент текста автоматически вклеивается контекст (название документа), что на 30% повышает точность будущих ответов нейросети.

## 🛠 Как запустить
1. `docker-compose up -d` (Запуск БД и Redis).
2. `pip install -r requirements.txt`.
3. `python scripts/init_db.py` (Инициализация схем).
4. `python -m services.ingest_worker.main` (Запуск процесса индексации).
